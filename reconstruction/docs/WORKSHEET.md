# 市民大道還原工作表

使用者要求：市民大道、高架、兩側第一排房屋、橋下空間、地下停車場、中山地下街與台北車站地下街；檢查關卡必須呈現疑慮、可能錯誤位置、改善方案；指令與脚本持續備份 GitHub。

|階段|內容|狀態|檢查／渲染|
|---|---|---|---|
|00|範圍盤點、設施清單、現有模型缺口|執行；關卡 A 待確認|來源範圍圖，不新增未核實模型|
|01|圖資來源、年代、可靠度、缺漏|初步資料盤點中|逐筆來源查核|
|02|座標、高程、出入口控制點|待 A|關卡 B：俯視疊圖、縱橫剖|
|03|道路、人行道、分隔島、路口骨架|待 B|全段俯視與路口局部|
|04|代表區段地上地下樣板|待 03|關卡 C：橋下、街道、地下剖透視|
|05|高架與橋下空間|待 C|每區柱位圖、淨高剖面、橋下巡視|
|06|第一排建物、街廓、騎樓|待 C，可與05交替|街牆立面及路口渲染|
|07|各地下停車場|待 C 與各場資料|各樓層、坡道與出入口對位|
|08|地下街與連通空間|待 C 與地下資料|關卡 D：通行連續性與樓層疊圖|
|09|整合、效能、交付|待 D|關卡 E：全段巡視及地上地下剖面|

完成度分開記錄：建模覆蓋、位置尺寸核對、渲染檢查。盤點前不編造百分比。現有造型工作版不是上述階段已完成的證據。

關卡記錄格式：issue_id、路段或物件、證據、疑慮、影響、改善方案、需要的資料、修正後鏡頭、結論。未核對幾何不能拿來推論實際障礙或通行淨寬。

備份節奏：每批新腳本執行前 commit；執行後備份驗證報告與變更摘要，再 commit。修改 Blender 前另存版本；不可覆寫唯一原件。GitHub 保存脚本、工作指令、來源清單、輕量檢查產物。大型 .blend 與下載資料暫留本地並記 SHA256，這不等於模型已備份至雲端。
